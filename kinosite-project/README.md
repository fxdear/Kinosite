# 🎬 Kinosite Project

Два связанных веб-сайта для просмотра фильмов и информации о сериалах.

## 📁 Структура проекта

### 🏠 Kinosite (основной сайт)
- **glavnoe.html** - Главная страница с баннерами
- **catalog.html** - Каталог фильмов и сериалов
- **favorite.html** - Страница избранного
- **css/vse.css** - Стили основного сайта
- **js/script.js** - JavaScript функциональность

### 🐭 Big Mouth (сайт сериала)
- **index.html** - Главная страница сериала
- **album.html** - Фотоальбом сериала
- **css/style.css** - Стили сайта сериала
- **js/script.js** - JavaScript для сериала
- **media/** - Медиафайлы:
  - **characters/** - Фотографии персонажей
  - **gallery/** - Галерея кадров из сериала
  - **posters/** - Постеры и баннеры
  - **videos/** - Видео файлы

## 🚀 Запуск проекта

1. Откройте `kinosite/glavnoe.html` в браузере для доступа к основному сайту
2. Из каталога можно перейти на страницу сериала "Большая мышь"
3. Со страницы сериала можно вернуться в каталог кнопкой "Назад"

## ⚡ Функциональность

### Kinosite:
- 📱 Адаптивный дизайн
- 🎨 Темная/светлая тема
- 🔍 Поиск и фильтрация
- ❤️ Система избранного
- 🎬 Карусель баннеров

### Big Mouth:
- 🖼️ Галерея фотографий
- 📺 Плеер для трейлера
- 👥 Информация о персонажах
- 📖 Подробный сюжет

## 🔗 Навигация между сайтами

- Из каталога Kinosite → Карточка "Большая мышь" → Сайт сериала
- Из сайта сериала → Кнопка "Назад" → Каталог Kinosite

## 📝 Примечание

Все медиафайлы организованы в логические папки для удобства навигации и масштабируемости проекта.
